## 📖 このディレクトリで何をしているか

本ディレクトリでは、気象データ特有の「ゼロ過剰（降水なしの日が大多数）」や「極端な大雨（ロングテール分布）」といった不均衡・非線形な時系列データに対し、機械学習アルゴリズムを用いて日別降水量（`prcp`）を高精度に予測するパイプラインの開発と段階的な精度改善を行っています。

### 主な取り組み内容
1. **データ取得・前処理**:
   - Google BigQuery の公開データセット（`bigquery-public-data.noaa_gsod.gsod2006` および `stations`）から日本全国の観測所データ（93,239件）を取得。
   - 欠損値コード・未観測フラグのクレンジング、観測所ごとの補間処理。
2. **時系列予測モデルの構築と段階的最適化**:
   - ベースライン（LightGBM単体）から特徴量エンジニアリング、アンサンブル、対数変換、2段階（Zero-Inflated）モデリングまで、段階を踏んでアプローチを検証・比較。
3. **性能評価・可視化**:
   - 平均絶対誤差（MAE）および平均二乗誤差（MSE）による定量評価。
   - 主要都市（松本、福井など）における予測値と実績値の時系列プロット、特徴量重要度（Feature Importance）の可視化。

## 💡 `Timeseries_analysis.ipynb` 内の分析・モデリングにおける工夫点

Jupyter Notebook（[`Timeseries_analysis.ipynb`](file:///home/t1aok/workspace/Timeseries-analysis/Timeseries_analysis.ipynb)）で実施した主要な工夫点は以下の通りです。

### 1. 気象物理と時系列周期を捉えた特徴量エンジニアリング
- **1週間の時系列ラグ（7日間）**:
  - 天気の周期的な移り変わりや持続性をモデルが捉えられるよう、従来の3日ラグから過去1〜7日前の降水量および気温のラグ特徴量を導入。
- **気象ドメイン知識に基づく外部変数の拡充**:
  - 雨が降る直前の「気圧低下」や「湿度の高まり」「強風」といった前兆現象を捉えるため、**海面気圧 (`slp`)**、**露点温度 (`dewp`)**、**風速 (`wdsp`)** の過去1〜3日前のラグ変数を追加生成（計27特徴量）。
  - 特徴量重要度（Feature Importance）分析を実施し、前日の海面気圧（`slp_lag_1`）や風速が予測精度向上に大きく寄与していることを実証。
- **時間・地理コンテキストの抽出**:
  - `month`（季節性）、`day`、`dayofweek`（曜日）のカレンダー特徴量と、観測所コード（`station_code`）を説明変数に含め、複数都市を単一モデルで横断学習（Global Forecasting）する構造を実現。

### 2. データクレンジングと欠損値・未観測コードの精緻な補間設計
- **未観測コードの適切な置換**:
  - 降水量の未観測コード `99.99` は実質的な無雨扱いとして `0.0` に置換。
  - 海面気圧（`9999.9`）、露点温度（`9999.9`）、風速（`99.9`, `999.9`）などの特殊な未観測コードを検出し、数値変換および `NaN` 化を実施。
- **観測所ごとのグループ補間（多層フォールバック）**:
  - 気象変数の欠損値に対して単純な全体平均で埋めるのではなく、まず「同一観測所（都市）内の平均値」で補間し、それでも埋まらない場合に全体平均を適用する2段階補間を採用。各地域の気候特性を壊さないよう配慮。

### 3. 未来情報リークを防止する時系列分割（Time-based Split）
- ランダムなK-Foldクロスバリデーションを行うと未来の気象データから過去を予測するデータリークが生じるため、実運用を想定して **時系列順での分割**（2006年1月〜9月を訓練データ、10月1日以降をテストデータ）を実施。
- 各観測所ごとにソートした上でラグ特徴量を生成し、年初のラグ欠損期間（7日間）を適切に除外して学習を実施。

### 4. アルゴリズム多様化によるバギングアンサンブル
- 木の分岐基準やブースティング手法の設計思想が異なる2大勾配ブースティング決定木ライブラリ **LightGBM** と **XGBoost** を組み合わせたバギングアンサンブル（予測値の単純平均）を構築。
- 単一モデル特有の過学習や突発的な外れ値予測を抑制し、予測の安定性を向上。

### 5. 目的変数の歪度とゼロ過剰に対する対数変換
- **課題**: 降水量データは「大多数が0」であり、雨天時は「少数の大雨・豪雨」が存在する右に極端に歪んだ分布（ロングテール）を持ちます。そのまま回帰学習を行うと、無雨の日にも不自然に小雨を予測してしまう「予測の浮き上がり」が発生し、MAEが悪化します。
- **工夫**:
  - 学習時に目的変数を $y' = \log(y + 1)$（`log1p`）に変換して大雨のスケールを圧縮。
  - 推論時に $\hat{y} = \max(\exp(\hat{y}') - 1, 0)$（`expm1` + クリッピング）で元のスケールに復元。
- **効果**: バギングモデルのMAEが **0.14476 → 0.12533** へと大幅に改善し、無雨日の誤予測を大幅に抑制。

### 6. 最優秀手法：2段階（Zero-Inflated）期待値モデリング + Optuna最適化
降水量予測の本質的な難所である「ゼロ過剰」に対し、問題自体を2つの異なるタスクに分解して解く高度なモデリング手法を採用。
- **構造分離（2フェーズ）**:
  1. **第1段階 (分類モデル)**:
     - `LGBMClassifier` を用い、「今日、雨が降るか否か（$y > 0$）」の降水確率 $P(\text{Rain})$ を予測（ROC-AUC: 0.8673）。
  2. **第2段階 (雨量回帰モデル)**:
     - 過去に雨が降った日（$y > 0$）のみのデータセットを抽出し、雨が降った場合の対数降水量 $S(\text{Amount})$ を `LGBMRegressor` で予測。
  3. **統合予測（期待値アプローチ）**:
     - 最終予測値を **降水確率 $\times$ 予測降水量**（$P(\text{Rain}) \times \hat{S}(\text{Amount})$）として算出。
- **Optunaによるハイパーパラメータ自動探索**:
  - 分類モデルと回帰モデルのそれぞれについて、決定木の深さ（`max_depth`）、葉の数（`num_leaves`）、最小子サンプル数（`min_child_samples`）、特徴量・行サンプリング比率（`colsample_bytree`, `subsample`）、学習率（`learning_rate`）をベイズ最適化（各15 trials）。
- **結果**:
  - **MAE: 0.11267 / MSE: 0.11668** を達成。初期ベースラインから約 **31.1%** の誤差削減に成功。
